# Elecrow-HMI-Display-LVGL-9.5-Base
Elecrow HMI Display LVGL 9.5 Base Project for ESP32 HMI Display-Basic Series

Deutsch:
Dieses Beispiel ist für die ESP32 HMI Display-Basic Series Displays 5" und 7" und LVGL 9.5
Mit kleinen Anpassungen der PIN-Konfiguration sollte es auch für die kleineren Displays funktionieren.

English:
This example is for the ESP32 HMI Display-Basic Series 5" and 7" displays and LVGL 9.5
With small adjustments to the pin configuration, it should also work for the smaller displays.
